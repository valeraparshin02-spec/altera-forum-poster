# Форум Альтеры — живая афиша

Отдельный вариант сайта форума «Стратегии и тренды рынка недвижимости».
16–17 апреля 2027, Казань, IT-парк имени Башира Рамеева.

Содержание синхронизировано с первым сайтом: организатор — агентство недвижимости «Альтера»; четыре предварительных направления программы; расписание, спикеры и партнёрские условия готовятся к анонсу. Билеты пока не продаются.

## Редактирование
`index.html` — содержание; `poster.css` — оформление; `poster.js` — анимация и видео; `assets/` — локальные медиа и шрифты.

## Публикация
GitHub Pages, ветка `main`, корень репозитория. Push обновляет сайт автоматически.
Для локального просмотра: `python -m http.server 8770`.
